CTEditor — Datos del juego en Excel
====================================
Cada archivo .csv es una hoja: una FILA por ficha, identificada por su columna 'id'.
  • Ábrelos con Excel (o LibreOffice / Google Sheets). Guarda como 'CSV UTF-8' o 'CSV (delimitado por punto y coma)'.
  • Filas con un id NUEVO crean fichas; filas con un id existente las actualizan.
  • Borrar una fila NO borra la ficha (para borrar usa el editor de su categoría).
  • Puedes quitar columnas que no quieras tocar: solo se aplican las que estén.
  • Antes de aplicar, Unity te enseña qué va a cambiar y guarda una copia de seguridad.
  • Listas: separa con |   Pares: clave:valor   Decimales: coma o punto.

── tipos.csv  (Tipos)
   id                       Id único (ej. fire).
   nombre                   Nombre visible (ej. Fuego).
   color                    Color en hexadecimal (ej. EE8130).

── tabla_tipos.csv  (Tabla de tipos)
   ataca\defiende           Primera columna: el tipo que ATACA. Cabecera: los tipos que DEFIENDEN.
   (celdas)                 2 = muy eficaz, 0,5 = poco eficaz, 0 = inmune, vacío = normal (×1).

── grupos_huevo.csv  (Grupos huevo)
   id                       Id (único, sin espacios). texto
   nombre                   Nombre visible. Nombre visible (Monstruo, Agua 1...). [texto]
   color                    Color. Color de la etiqueta en los editores. [color hex, ej. EE8130]
   no_cria                  No puede criar. Si está marcado, las especies de este grupo NO pueden criar (como «Desconocido»). [si / no]
   descripcion              Descripción. Descripción para el autor. [texto]

── estados.csv  (Estados)

   daño_creciente           El daño crece cada turno. Si está marcado, el daño residual escala cada turno (envenenamiento grave / tóxico). [si / no]

   se_cura_al_retirarse     Se cura al retirarse. Si está marcado, el estado se quita al cambiar de monstruo (estados volátiles). [si / no]
   duracion                 Duración en turnos (0 = hasta curarse). Duración en turnos. 0 = permanente (hasta curar). >0 = se quita solo tras esos turnos (p.ej. sueño). [número entero]
   prob_recuperarse         Probabilidad de recuperarse cada turno (%). Probabilidad por turno de recuperarse solo (dormido/confuso despiertan al azar). 0 = solo por duración. [número]
   autodaño                 Autodaño al no actuar (% PS máx.). Si impide la acción, daño que el portador se hace a sí mismo (% PS máx). Confusión > 0; dormido = 0. [número]
   se_convierte_en          Al terminar se convierte en. Al terminar, se convierte en este estado en vez de curarse (somnoliento -> dormido). Vacío = se cura. [id de StatusCondition]
   modificadores            Cambios de estadísticas mientras dura. Modificadores pasivos de estadísticas mientras dura (p.ej. Ataque ×0,5 para quemado). [filas con |, campos con ':' en este orden: estadistica:multiplicador]
   tipos_inmunes            Tipos inmunes. Tipos que NO pueden sufrir este estado (Fuego no se quema, Eléctrico no se paraliza...). Vacío = cualquiera. [lista con |: id de ElementType]

   impide_cambio            Impide cambiarse y huir. El portador no puede cambiarse ni huir (Atadura, Mal de Ojo). [si / no]
   bloquea_ataques          Bloquea los ataques del rival. Los movimientos del rival contra el portador fallan (Protección). Úsalo con duración 1. [si / no]
   aguanta                  Aguanta con 1 PS. Un golpe que lo debilitaría lo deja con 1 PS (Aguante). Úsalo con duración 1. [si / no]
   cura_al_rival            El daño por turno cura al rival. El daño por turno CURA al rival que está en el campo (Drenadoras). [si / no]
   mas_dificil_si_repite    Más difícil si se repite. Si se usa turnos seguidos, cada vez es más difícil que salga (Protección: 1/3, 1/9...). [si / no]
   captura_x                Facilita la captura (×). Cuánto facilita capturar a un monstruo con este estado (1 = nada). Clásico: dormido y congelado 2,5; paralizado, envenenado y quemado 1,5. [número]
   bloquea_estado           No puede usar movimientos de estado (Mofa). No puede usar movimientos de estado (Mofa). [si / no]
   bloquea_repetir          No puede repetir movimiento (Tormento). No puede repetir el mismo movimiento dos turnos seguidos (Tormento). [si / no]
   bloquea_curar            No puede curarse (Anticura). No puede curarse (Anticura). [si / no]
   bloquea_objetos          No puede usar objetos (Embargo). No puede usar objetos (Embargo). [si / no]
   anula_habilidad          Anula su habilidad (Bilis). Su habilidad deja de funcionar (Bilis). [si / no]
   daño_si_estado           El daño por turno necesita este estado. El daño por turno solo ocurre si además tiene este estado (Pesadilla: sleep). Si no lo tiene, el volátil se va. [id de StatusCondition]
   debilita_al_acabar       Se debilita al acabar (Canto Mortal). Al acabarse, el portador se debilita (Canto Mortal). [si / no]
   mismo_destino            Mismo Destino. Si un ataque lo debilita mientras dura, el atacante también cae (Mismo Destino). [si / no]
   rabia                    Rabia (deja sin PP). Si un ataque lo debilita, ese movimiento se queda sin PP (Rabia). [si / no]
   devuelve_estado          Devuelve los de estado (Capa Mágica). Devuelve los movimientos de estado que le lanzan (Capa Mágica). [si / no]
   robo                     Roba las mejoras (Robo). Se queda las mejoras propias que use el rival (Robo). [si / no]
   tipo_potenciado          Tipo potenciado (Carga). Su próximo movimiento de este tipo hace más daño (Carga: Eléctrico). [id de ElementType]
   tipo_potenciado_mult     Multiplicador del tipo potenciado. número
   refuerzo_se_gasta        El refuerzo se gasta. El refuerzo se gasta al usar ese tipo. [si / no]
   inmune_tipos_extra       Inmune a estos tipos mientras dura (Levitón). Tipos a los que es inmune mientras dura (Levitón: Tierra). [lista con |: id de ElementType]
   pierde_tipo              Pierde este tipo mientras dura (Respiro). Pierde este tipo mientras dura (Respiro: Volador). [id de ElementType]
   identificado             Identificado (Profecía). Identificado: se ignora su evasión y le alcanzan los tipos de abajo aunque fuera inmune (Profecía, Gran Ojo). [si / no]
   alcanzable_por           Le alcanzan estos tipos aunque fuera inmune. lista con |: id de ElementType
   no_falla                 Su próximo movimiento no falla (Fijar Blanco). Su próximo movimiento no falla (Fijar Blanco). Se pone en quien lo usa. [si / no]
   cerca                    Cerca (el rival no usa sus movimientos). El rival no puede usar los movimientos que el portador conoce (Cerca). [si / no]
   en_suelo                 En el suelo (Arraigo, Gravedad). En el suelo: le afecta Tierra aunque vuele o levite (Arraigo). [si / no]
   genero_opuesto           Solo al género opuesto (Atracción). Solo afecta a un rival del género OPUESTO al de quien lo causa (Atracción, Gran Encanto). Nunca a los sin género. [si / no]
   protege_solo_daño        Protege solo de ataques que hacen daño (Escudo Real). La protección solo para los movimientos que hacen daño (Escudo Real, Escudo Tatami). [si / no]
   protege_baja_stat        Al bloquear contacto: estadística que baja al atacante. Si le golpean con contacto mientras se protege, el atacante pierde etapas de esta estadística (Escudo Real: attack). [texto]
   protege_baja_etapas      Al bloquear contacto: etapas que baja. número entero
   protege_daño             Al bloquear contacto: % de PS que pierde el atacante. Si le golpean con contacto mientras se protege, el atacante pierde este % de PS (Barrera Espinosa: 12,5). [número]
   protege_estado           Al bloquear contacto: estado que sufre el atacante. Si le golpean con contacto mientras se protege, el atacante sufre este estado (Búnker: poison). [id de StatusCondition]
