CTEditor — Datos del juego en Excel
====================================
Cada archivo .csv es una hoja: una FILA por ficha, identificada por su columna 'id'.
  • Ábrelos con Excel (o LibreOffice / Google Sheets). Guarda como 'CSV UTF-8' o 'CSV (delimitado por punto y coma)'.
  • Filas con un id NUEVO crean fichas; filas con un id existente las actualizan.
  • Borrar una fila NO borra la ficha (para borrar usa el editor de su categoría).
  • Puedes quitar columnas que no quieras tocar: solo se aplican las que estén.
  • Antes de aplicar, Unity te enseña qué va a cambiar y guarda una copia de seguridad.
  • Listas: separa con |   Pares: clave:valor   Decimales: coma o punto.

── tipos.csv  (Tipos)
   id                       Id único (ej. fire).
   nombre                   Nombre visible (ej. Fuego).
   color                    Color en hexadecimal (ej. EE8130).

── tabla_tipos.csv  (Tabla de tipos)
   ataca\defiende           Primera columna: el tipo que ATACA. Cabecera: los tipos que DEFIENDEN.
   (celdas)                 2 = muy eficaz, 0,5 = poco eficaz, 0 = inmune, vacío = normal (×1).

── estados.csv  (Estados)
   id                       Id (único, sin espacios). texto
   nombre                   Nombre visible. texto
   volatil                  Es volátil (se suma al principal). PRINCIPAL (desmarcado): quemado, parálisis, sueño... solo uno a la vez. VOLÁTIL (marcado): confusión, atrapado, drenadoras... se suma al principal y a otros volátiles, y se va al retirarse. [si / no]
   daño_por_turno           Daño por turno (% PS máx.). Daño por turno como % de los PS máximos. 0 = no hace daño (p.ej. parálisis). [número]
   daño_creciente           El daño crece cada turno. Si está marcado, el daño residual escala cada turno (envenenamiento grave / tóxico). [si / no]
   cura_por_turno           Cura en vez de dañar. Si está marcado, el residual CURA en vez de dañar cada turno (regeneración). [si / no]
   prob_no_actuar           Probabilidad de no actuar (%). Probabilidad por turno de no poder actuar. 0 = nunca impide (p.ej. quemado). [número]
   se_cura_al_retirarse     Se cura al retirarse. Si está marcado, el estado se quita al cambiar de monstruo (estados volátiles). [si / no]
   duracion                 Duración en turnos (0 = hasta curarse). Duración en turnos. 0 = permanente (hasta curar). >0 = se quita solo tras esos turnos (p.ej. sueño). [número entero]
   prob_recuperarse         Probabilidad de recuperarse cada turno (%). Probabilidad por turno de recuperarse solo (dormido/confuso despiertan al azar). 0 = solo por duración. [número]
   autodaño                 Autodaño al no actuar (% PS máx.). Si impide la acción, daño que el portador se hace a sí mismo (% PS máx). Confusión > 0; dormido = 0. [número]
   se_convierte_en          Al terminar se convierte en. Al terminar, se convierte en este estado en vez de curarse (somnoliento -> dormido). Vacío = se cura. [id de StatusCondition]
   modificadores            Cambios de estadísticas mientras dura. Modificadores pasivos de estadísticas mientras dura (p.ej. Ataque ×0,5 para quemado). [filas con |, campos con ':' en este orden: estadistica:multiplicador]
   tipos_inmunes            Tipos inmunes. Tipos que NO pueden sufrir este estado (Fuego no se quema, Eléctrico no se paraliza...). Vacío = cualquiera. [lista con |: id de ElementType]
   duracion_max             Duración máxima (al azar). Si es mayor que 'Duration Turns', la duración se sortea entre ambos (Atadura: 4 a 5 turnos). [número entero]
   impide_cambio            Impide cambiarse y huir. El portador no puede cambiarse ni huir (Atadura, Mal de Ojo). [si / no]
   bloquea_ataques          Bloquea los ataques del rival. Los movimientos del rival contra el portador fallan (Protección). Úsalo con duración 1. [si / no]
   aguanta                  Aguanta con 1 PS. Un golpe que lo debilitaría lo deja con 1 PS (Aguante). Úsalo con duración 1. [si / no]
   cura_al_rival            El daño por turno cura al rival. El daño por turno CURA al rival que está en el campo (Drenadoras). [si / no]
   mas_dificil_si_repite    Más difícil si se repite. Si se usa turnos seguidos, cada vez es más difícil que salga (Protección: 1/3, 1/9...). [si / no]
   captura_x                Facilita la captura (×). Cuánto facilita capturar a un monstruo con este estado (1 = nada). Clásico: dormido y congelado 2,5; paralizado, envenenado y quemado 1,5. [número]

── climas.csv  (Climas)
   id                       Id (único, sin espacios). Id estable (lo usan los movimientos y las condiciones). Ej.: rain [texto]
   nombre                   Nombre visible. texto
   turnos                   Turnos que dura. Turnos que dura cuando un movimiento lo activa sin indicar duración. 0 = hasta que otro clima lo reemplace. [número entero]
   potencia_por_tipo        Potencia por tipo. Multiplicadores de potencia por tipo mientras dura. Lluvia: Agua ×1,5 y Fuego ×0,5. [filas con |, campos con ':' en este orden: tipo:multiplicador]
   daño_por_turno           Daño por turno (% PS máx.). Daño a TODOS al final de cada turno (% de PS máx). Arena/granizo: 6,25. 0 = nada. [número]
   tipos_inmunes            Tipos inmunes. Tipos que NO reciben ese daño (arena: Roca, Tierra y Acero). [lista con |: id de ElementType]
   color                    Color. Color para la interfaz (fondo del combate, etiquetas). [color hex, ej. EE8130]

── trampas.csv  (Trampas de campo)
   id                       Id (único, sin espacios). texto
   nombre                   Nombre visible. texto
   color                    Color. Color para reconocerla en los editores. [color hex, ej. EE8130]
   capas                    Capas máximas. Cuántas veces se puede poner (Púas: 3, Púas Tóxicas: 2, Trampa Rocas: 1). [número entero]
   daño_por_capa            Daño por capa (% PS máx.). % de los PS máximos que quita al entrar, por capa (1.ª, 2.ª, 3.ª...). Púas: 12,5 · 16,67 · 25. Vacío = no daña. [lista con |: número]
   tipo_daño                Daño × eficacia del tipo. Si eliges un tipo, el daño se multiplica por su eficacia contra el que entra (Trampa Rocas: Roca → un Charizard recibe ×4). [id de ElementType]
   estado_por_capa          Estado por capa. Estado que inflige, por capa (Púas Tóxicas: poison, toxic). Vacío = ninguno. [lista con |: id de StatusCondition]
   estadistica              Estadística. Estadística cuya etapa cambia al entrar (Red Viscosa: speed). Vacío = ninguna. [texto]
   etapas                   Etapas. Etapas que cambia (Red Viscosa: -1). [número entero]
   tipos_inmunes            Tipos inmunes. Tipos que no la notan (Volador, para las que están en el suelo). [lista con |: id de ElementType]
   inmune_por_habilidad     Inmune si su habilidad bloquea el tipo. Si la habilidad del que entra le hace inmune a ESTE tipo, no la nota (Levitación → Tierra). [id de ElementType]
   la_retiran               La retiran los tipos. Tipos que, al entrar, la RETIRAN de su lado (Veneno retira las Púas Tóxicas). [lista con |: id de ElementType]

── efectos_lado.csv  (Efectos de lado)
   id                       Id (único, sin espacios). texto
   nombre                   Nombre visible. texto
   color                    Color. Color para reconocerlo en los editores. [color hex, ej. EE8130]

   mult_especial            Daño especial recibido ×. Multiplicador del daño ESPECIAL recibido. 1 = normal; Pantalla de Luz: 0,5. Los críticos lo ignoran. [número]

   sin_estados              Impide estados. El rival no puede poner ESTADOS a este lado (Velo Sagrado). [si / no]
   mult_velocidad           Velocidad ×. Multiplicador de la Velocidad de este lado. 1 = normal; Viento Afín: 2. [número]

── habilidades.csv  (Habilidades)
   id                       Id (único, sin espacios). Id estable de la habilidad (clave de texto, p.ej. "levitate"). [texto]
   nombre                   Nombre visible. texto
   modificadores            Cambios de estadísticas mientras dura. Multiplica estadísticas mientras el portador está en combate (p.ej. ataque ×2). Se combina en EffectiveStat. [filas con |, campos con ':' en este orden: estadistica:multiplicador]
   inmune_estados           Inmune a los estados. Estados que esta habilidad IMPIDE (no se pueden infligir al portador). [lista con |: id de StatusCondition]
   inmune_tipos             Inmune a los tipos. Tipos a los que el portador es INMUNE (los movimientos de ese tipo no le afectan). [lista con |: id de ElementType]
   cura_al_absorber         Cura al absorber (% PS máx.). Si es inmune a un tipo, % de PS máx que CURA al recibirlo (Absorbe Agua). 0 = solo anula. [número]
   estado_por_contacto      Estado al recibir contacto. Estado a infligir al ATACANTE cuando le pega un golpe de CONTACTO (Estática, Cuerpo Llama). Vacío = ninguno. [id de StatusCondition]
   prob_contacto            Probabilidad por contacto (%). Probabilidad de la reacción por contacto. [número]
   entrada_stat             Al entrar: estadística. Al ENTRAR al campo, cambia una etapa de estadística (Intimidación: estadística "attack", -1, al rival). Vacío = nada. [texto]
   entrada_etapas           Al entrar: etapas. número entero
   entrada_propio           Al entrar: sobre sí mismo. Si está marcado, el cambio al entrar es sobre uno mismo; si no, sobre el rival. [si / no]
   con_estado_stat          Con estado: estadística que sube. Stat que se multiplica SOLO si el portador tiene un estado (Agallas: "attack"; Pies Rápidos: "speed"). Vacío = nada. [texto]
   con_estado_mult          Con estado: multiplicador. número
   poca_vida_tipo           Poca vida: tipo potenciado. Tipo de movimiento potenciado al atacar con poca vida (Espesura: fuego). Vacío = nada. [id de ElementType]
   poca_vida_umbral         Poca vida: umbral (% PS). Umbral de PS (% del máx) bajo el cual se activa el refuerzo a poca vida. [número]
   poca_vida_mult           Poca vida: multiplicador. número
   daño_recibido_tipo       Daño recibido por tipo. Daño ENTRANTE por tipo: multiplicadores (Sebo: Fuego x0.5 y Hielo x0.5). [filas con |, campos con ':' en este orden: tipo:multiplicador]
   stab                     Multiplicador de mismo tipo (0 = 1,5). Multiplicador STAB explícito (Adaptable = 2). 0 = clásico (1.5). [número]
   prioridad_estado         Prioridad extra en movimientos de estado. Bonus de prioridad para movimientos de ESTADO (Vista Lince = 1). [número entero]
   impide_bajadas           Impide que le bajen estadísticas. Impide que el RIVAL le baje etapas de estadística (Cuerpo Puro). [si / no]
   cura_al_retirarse        Se cura el estado al retirarse. Al cambiarse (salir), cura su estado alterado (Cura Natural). [si / no]
   cura_ps_al_retirarse     Cura al retirarse (% PS máx.). Al cambiarse, recupera este % de PS máx (Regeneración = 33). [número]
   fin_turno_stat           Fin de turno: estadística. Al fin de turno, cambia una etapa de estadística propia (Impulso: "speed"). Vacío = nada. [texto]
   fin_turno_etapas         Fin de turno: etapas. número entero
   fin_turno_cura           Fin de turno: cura (% PS máx.). Al fin de turno, recupera este % de PS máx (Cura Veneno = 12.5). [número]
   fin_turno_con_estado     Fin de turno: solo si tiene estado. Si está marcado, esa curación solo ocurre si el portador TIENE estado (Cura Veneno). [si / no]
   fin_turno_curar_estado   Fin de turno: prob. de curarse el estado (%). Al fin de turno, probabilidad de curarse el estado (Mudar = 30). [número]
   anula_daño_estado        Anula el daño de los estados. Anula el daño residual de estados (Cura Veneno / Guardia Mágica). [si / no]
   potencia_al_atacar       Ej.: x1,5 [si mov.potencia<=60] | x1,2 [si mov.etiqueta=puño]
   potencia_al_recibir      Ej.: x0,5 [si mov.contacto]  ('propio' = quien tiene la habilidad)

── movimientos.csv  (Movimientos)
   id                       Id único (ej. ember).
   nombre                   Nombre visible.
   tipo                     Id del tipo (ej. fire).
   categoria                fisico, especial o estado.
   potencia                 0 para movimientos de estado.
   precision                0-100, o 'nunca' si nunca falla.
   pp                       Usos máximos (ej. 25).
   prioridad                0 normal; +1 Ataque Rápido.
   objetivo                 rival, propio, rivales, aliado o todos.
   golpes                   1, 2, o un rango 2-5.
   critico                  0 normal; 1 o más = crítico alto.
   dos_turnos               no, carga o recarga.
   contacto                 si / no.
   daño_especial            Vacío = normal. fijo:40 (siempre 40 PS), nivel (PS = nivel del usuario), mitad (mitad de los PS del rival), ko (KO directo), devolver_fisico / devolver_especial (Contraataque / Manto Espejo: el doble del daño recibido; :150 = 150 %), venganza (aguanta 2 turnos y devuelve el doble).
   respeta_inmunidad        Solo movimientos de estado: si = no afecta a inmunes por tipo (Onda Trueno vs Tierra).
   potencia_mod             Multiplicadores con condiciones: x2 [si propio.estado] | x1,5 [si clima=rain]. Vacío = ninguno.
   formula_potencia         Opcional, reemplaza la potencia. Variables: potencia, nivel, nivel_rival, vida, vida_rival, amistad, velocidad, velocidad_rival. Ej.: 150*vida/100
   stat_ataque              Vacío = la de su categoría. Ej.: defense (Golpe Cuerpo con Defensa), suerte (estadística inventada).
   stat_defensa             Vacío = la de su categoría. Psicocarga: defense.
   ataca_con_rival          si = usa la estadística de ataque DEL RIVAL (Juego Sucio).
   etiquetas                Etiquetas libres: puño|sonido|mordisco.
   requisitos               Solo funciona si se cumple (vacío = siempre). Ej.: rival.estado=sleep (Comesueños) · propio.estado=sleep (Ronquido). Varias con &.
   efectos                  estado:burn@10 | drenar:50 | retroceso:33 | retroceso_ps:25 | curar:50 | curar_rival:50 | curar_estado | clima:rain | stat:attack:-1 | stat_propio:speed:+2 | amedrentar@30 · condiciones: [si rival.vida<50] · mismo dado que el anterior: &efecto
   animacion                Segundos de animación (solo presentación).

   categoria                Categoría: Semilla (se ve «Pokémon Semilla»).
   altura                   Altura en metros (0,7).
   peso                     Peso en kilos (6,9).
   color                    Color principal: verde, rojo, azul...
   hembras                  % de hembras (0-100) o sin_genero.
   legendario               si / no.
   descripcion              Texto de la Pokédex.

── entrenadores.csv  (Entrenadores)
   id                       Id único (ej. lider_brock).
   nombre                   Nombre del entrenador.
   clase                    Clase (Joven, Cazabichos, Líder de gimnasio...).
   ia                       Nivel de IA: novato, listo o experto.
   usa_objetos              si / no: ¿usa los objetos de su mochila?
   mochila                  objeto:cantidad separados por |. Ej.: hyper_potion:2 | full_heal:1
   curar_bajo               Se cura con este % de PS o menos (1-100). Clásico: 25.
   puede_cambiar            si / no: ¿puede cambiar de monstruo? (solo la IA experta lo hace).
   movimientos_auto         Miembros sin movimientos escritos: ia (según su IA), clasico (4 últimos), equilibrado o fuerte.
   dinero_base              Premio = este valor × nivel de su último monstruo.
   equipo                   Miembros separados por |. especie@nivel y, opcional: [mov1/mov2] {objeto} ~naturaleza #iv "mote". Ej.: pidgey@5 | onix@14[tackle/rock_throw]{oran_berry}
   frase_inicio             Lo que dice al empezar.
   frase_derrota            Lo que dice al perder.
   frase_victoria           Lo que dice si gana.

── zonas.csv  (Zonas salvajes)
   id                       Id único (ej. ruta_1).
   nombre                   Nombre visible.
   especies                 especie@min-max:frecuencia separadas por |. Ej.: pidgey@2-5:50 | rattata@2-4:50

── equipos.csv  (Equipos prearmados)
   id                       Id único (ej. equipo_prueba_50).
   nombre                   Nombre visible.
   descripcion              Para qué sirve.
   dinero                   Dinero inicial (-1 = el de las reglas).
   equipo                   Miembros separados por |. especie@nivel y, opcional: [mov1/mov2] {objeto} ~naturaleza #iv "mote". Ej.: pidgey@5 | onix@14[tackle/rock_throw]{oran_berry}
   mochila                  objeto:cantidad separados por |. Ej.: potion:5 | poke_ball:10
